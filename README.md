# Retired: Infinity3 is built in OpenIPC/u-boot

This repository is archived. U-Boot for MSC313E, MSC316DC and MSC316DM is now
built from the same tree as every other SigmaStar SoC OpenIPC supports: the
`openipc-sigmastar` branch of
[OpenIPC/u-boot](https://github.com/OpenIPC/u-boot/tree/openipc-sigmastar),
with its CI on the `openipc` branch. Those builds are published as
`u-boot-msc313e-nor.bin`, `u-boot-msc316dc-nor.bin` and
`u-boot-msc316dm-nor.bin` in its
[`sigmastar`](https://github.com/OpenIPC/u-boot/releases/tag/sigmastar)
release.

The history here stays readable for reference.
